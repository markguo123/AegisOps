## 2. P10 确定性边界测试（方案第 4 节）

```
go test ./internal/agent -run 'Test(Compaction|RequestBudget|LargeResult|SensitiveResults|Reader|ResultReader|ReadRetry|UnknownWrite|PermissionDenial|BatchFailure|HistoryObservations)' -count=1 -v
```

- `TestCompactionPreservesTargetAndLatestToolBatchWithoutSecrets`：压缩保留目标与最新 tool batch、不带 Secret
- `TestCompactionFailureIsBoundedAndDoesNotDiscardHistory`（empty / tool-call / error / cancel / request-limit）：压缩失败有界、不丢历史
- `TestRequestBudgetIncludesSchemaAndOutputReserve`：请求预算包含工具 Schema 与输出预留
- `TestLargeResultPagingAndOwnership`：大结果分页与归属
- `TestSensitiveResultsAndReaderNeverSpill`（model-only / known-secret / reader）：敏感结果不进摘要/存储
- `TestReaderRejectsUnknownReferencesAndBudgets`、`TestResultReaderRegistryIsIsolatedAndCanBeDisabled`、`TestReaderReferencesExpireWhenTurnEnds`：引用隔离/过期、可按归属/集群/授权撤销
- `TestReadRetryBudgetAndCanonicalArguments`：受控只读重试
- `TestUnknownWriteCannotBeReplayedOrFollowedByAnotherWrite`：未知写结果不重放、不再跟随写操作
- `TestPermissionDenialFeedbackNeverSuggestsRetry`：权限拒绝不提示重试
- `TestBatchFailureCompletesProtocolWithoutExecutingRemainder`：批失败完成协议、不执行剩余
- `TestHistoryObservationsDoNotCreateOrphanedToolMessages`：历史观察不产生孤立 tool 消息

### 4.1 现场遇到的问题（本轮重要发现）

1. ~~登录凭据与运行服务不一致（阻断 API 级验收）~~ **✅ 已解开（续测发现为假象）**：
   初判 `POST /api/v1/auth/login` 对 `admin/AegisOps@123` 返回 `400 invalid credentials` 属误报。
   续测对同一服务直接补「浏览器式」来源协商（`Origin: https://aegisops.10.62.107.200.nip.io` + `Referer`，并按响应 `set-cookie` 携带
   `__Host-aegisops_session` / `__Host-aegisops_csrf` Cookie 链）后返回 `200`，用户为 `admin`，签发 `expiresAt=2026-11-11T12:03:51Z`。
   即**口令有效、凭据对齐**：此前缺失 `Origin`/CSRF 协商导致来源判定失败（无 `Origin` 时返回 `403 request origin or CSRF token is invalid`），
   并非服务内口令不一致。代码路径 `internal/server/browser.go` 的登录判定依赖浏览器来源头，驱动方需按浏览器约定发起。
   该解除意味着**HTTP 认证通道可通**，T1–T5 的登录前置不再阻断。

2. **本会话 kubectl 被宿主进程级策略拒绝（环境障碍，非产品缺陷）**：
   普通 pwsh 可执行，但读取 `%USERPROFILE%\.kube\config` / 调用 kubectl（含 `--kubeconfig`）的命令在宿主层被拒绝，与 AppCloud「完全权限」界面开关无关。因此本记录不代跑 `kubectl create/delete`，测试资源的创建与清理需用户在本机或集群侧完成。
