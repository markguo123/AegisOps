## Argo CD 企业登录

借鉴 [Argo CD 的 OIDC claims 请求](https://github.com/argoproj/argo-cd/blob/cfb8954fbc5a5de1178291204663cfea682b2a44/util/oidc/oidc.go)。直接移植 createClaimsAuthenticationRequestParameter 至 internal/auth/oidc_claims.go，仅保留 essential 字段。企业登录配置了组准入时请求对应 ID Token claim，回调独立检查。TestIDTokenClaims 移植于 internal/auth/oidc_claims_test.go。许可证随附于 third_party/argo-cd/LICENSE。

同一 Argo CD 提交的 GetScopesOrDefault 原样复制到 internal/auth/oidc_claims.go，企业组准入启用时使用上游默认 scopes。未启用组准入时传入明确的 openid/profile/email，与既有配置行为一致。
